# Referensi tema

Berkas-berkas HTML di folder ini adalah tiruan dari papan desain dan hanya acuan rupa, bukan kode yang disalin ke Onsa. Spektrum dan bagian berulang lainnya tidak tergambar tanpa runtime papan itu (`support.js`, yang tidak ikut disimpan), dan font dimuat dari internet saat berkas dibuka di browser. Bila sebuah referensi dan [`../../konsep-tema.md`](../../konsep-tema.md) berbeda, yang menang adalah `konsep-tema.md`.
